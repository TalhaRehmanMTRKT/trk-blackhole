# trk-blackhole

> ⚠️ **Archived / End-of-Life Repository**
>
> This repository is no longer maintained. It serves as an archive ("black hole") for older personal projects, coursework, and experiments that I want to keep around but no longer actively develop. Code here is provided as-is, may be incomplete, outdated, or use deprecated tooling.

## About

A collection of older work consolidated into a single repository for archival purposes. Most of the projects fall into one of these categories:

- **`*-namal`** — Coursework and projects completed during my **BSc Electrical Engineering** degree at **Namal University, Mianwali** (Pakistan).
- **`*-inu`** — Work produced during a **seminar at Incheon National University (INU)**, South Korea.
- **`trk-utils-*`** — Small personal utility/web mini-projects.
- Other folders — Miscellaneous experiments and deployment tests.
